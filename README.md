## 🌟 Projekt-Highlight: Prozessautomatisierung für einen Non-Profit-Verein (Bachelorarbeit)

Eine umfassende Fullstack-Lösung, entwickelt um die manuellen und zeitaufwändigen Prozesse eines lokalen Vereins zu digitalisieren und zu automatisieren. Das Ergebnis war eine signifikante Steigerung der Effizienz im Mitgliedermanagement.

**Tech Stack:** .NET MAUI (Frontend), Laravel (Backend), nach **Clean Architecture**-Prinzipien.

-   **Problemlösung:** Ersetzte aufwändige, papierbasierte Abläufe durch eine zentrale, benutzerfreundliche digitale Plattform.
-   **Kernfunktionen:** Implementierte automatisierte Workflows für die Mitgliederverwaltung, Eventplanung und Kommunikation.
-   **Architektur:** Nutzte eine geschichtete Architektur mit DTOs, AutoMapper und Entity Framework, um Wartbarkeit und Skalierbarkeit sicherzustellen.
-   **Ergebnis:** Lieferte eine plattformübergreifende Anwendung (Windows, Android), die dem Verein wöchentlich Stunden an manueller Arbeit ersparte.
